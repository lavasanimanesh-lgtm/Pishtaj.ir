## مبنای تأییدشده توسط کاربر

قیمت تخمینی تأمین به‌صورت عمومی قابل مشاهده باشد، نه قیمت مخفی و نه پیشنهاد قطعی فروش. فقط کالای نو و قیمت تک‌عددی وارد محاسبه شود.

```
برآورد تومان = قیمت ارزی تک‌عدد × نرخ فروش همان ارز به تومان × ۲
```

صد درصد افزایش با صد درصد حاشیه سود یکی نیست. هزینه حمل، بیمه، گمرک و مالیات تفکیکی محاسبه نشده است. شمول و مبلغ هزینه‌ها، امکان تأمین قانونی، اصالت، زمان تحویل و قیمت نهایی باید در پیش‌فاکتور مشخص شود.

## نگهداری و ادامه کار

داده‌ها نقطه‌زمانی هستند. صفحات حتی بعداً نیز صریحاً همان تاریخ مشاهده را نشان می‌دهند و ادعای «قیمت روز» ندارند. حذف خودکار قیمت قدیمی یا دریافت خودکار نرخ ارز وجود ندارد. پیش از انتشار و پیش از بازسازی، منابع باید مجدداً بررسی شوند.

```sh
python tools/build_price_estimates.py --as-of 2026-09-19
python -m unittest discover -s tools -p 'test_price_estimates.py'
python _tools/seo_redirect_audit.py
```

برای بازسازی در روز دیگر، ابتدا قیمت و نرخ را واقعاً بررسی و تاریخ مشاهده و شاهد را به‌روز کنید، سپس `--as-of` همان روز را بدهید. ابزار قیمت/نرخ بیش از یک روز قدیمی، تاریخ آینده، واحد ریال به‌جای تومان، ضریب غیر از ۲، شناسه تکراری، قیمت صفر/منفی و داده تأییدنشده را رد می‌کند. تاریخ تاریخی بالا فقط برای بازتولید خروجی این مرحله است، نه دور زدن کنترل تازگی در انتشار بعدی.

ابزار بلوک‌های قیمت را میان نشانگرهای اختصاصی جایگزین می‌کند و محتوای قبلی صفحات خانواده را حفظ می‌کند. اگر مدل با همان مسیر صفحه‌ای داشته باشد که متعلق به مولد نیست، ابزار متوقف می‌شود؛ نگاشت صریح و بررسی انسانی لازم است. حذف یک مدل از ورودی، صفحه قبلاً ساخته‌شده و sitemap آن را خودکار حذف نمی‌کند؛ بازنشسته‌کردن مدل باید با تصمیم ریدایرکت/حذف جداگانه انجام شود.
