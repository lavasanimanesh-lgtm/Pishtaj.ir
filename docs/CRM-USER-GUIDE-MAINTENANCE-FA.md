# قرارداد نگهداشت راهنمای CRM

**منبع راهنمای درون‌برنامه‌ای:** `crm/user-guide.js`  
**محل نمایش:** تنظیمات CRM → «راهنمای کامل استفاده از نرم‌افزار»

## قانون الزامی

هر تغییر که یکی از موارد زیر را عوض می‌کند، تا وقتی راهنمای درون‌برنامه‌ای به‌روزرسانی نشده باشد **کامل نیست**:

- ایجاد یا حذف ماژول، تب، فرم، دکمه، گزارش یا workflow
- تغییر نقش یا دسترسی کاربران
- تغییر ترتیب مراحل کسب‌وکار یا شرط انجام عملیات
- تغییر اثر مالی، Sync، ذخیره، بک‌آپ، حذف یا بازیابی داده
- اضافه‌شدن نوع سند، فیلد اجباری، روش پرداخت یا وضعیت جدید

## چک‌لیست Pull Request

- [ ] entry مرتبط در `GUIDE` داخل `crm/user-guide.js` به‌روزرسانی شد یا entry جدید افزوده شد.
- [ ] هدف، زمان استفاده، مراحل، خروجی و هشدار/مرز خطا نوشته شد.
- [ ] نقش‌های مجاز با رفتار واقعی RBAC هم‌خوان است.
- [ ] اگر اثر مالی دارد، زمان شناسایی هزینه/بدهی/نقد و جلوگیری از دوباره‌شماری توضیح داده شده است.
- [ ] اگر عملیات حساس است، مسیر بازگشت/ابطال یا هشدار کاربر توضیح داده شده است.
- [ ] تست قرارداد راهنما در گیت CI به‌روزرسانی شده است.

## استاندارد متن

- فارسی ساده و عملیاتی بنویسید؛ اصطلاح فنی بدون توضیح به‌کار نبرید.
- راهنما نباید وعده‌ای بدهد که نرم‌افزار واقعاً انجام نمی‌دهد.
- راهنما نباید اطلاعات حساس، رمز، توکن یا آدرس داخلی سرور را نمایش دهد.
- تاریخچه release در راهنما نگهداری نشود؛ راهنما باید فقط رفتار فعلی محصول را توضیح دهد.
