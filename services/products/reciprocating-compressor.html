خرید و تامین کمپرسور رفت‌وبرگشتی API 618 برای گاز فرایندی

تامین کمپرسور رفت‌وبرگشتی API 618 برای نفت، گاز و پتروشیمی؛ انتخاب Cylinder، Driver، Pulsation Bottle، Lubrication، Capacity Control و تست‌های مکانیکی.

راهنمای کاربردی برای تصمیم‌گیری

این صفحه برای خرید، طراحی، نصب، بهره‌برداری و بازرسی کمپرسور رفت‌وبرگشتی API 618 نوشته شده است. هدف این است که کاربر محصول بداند در RFQ، ساخت، تست، راه‌اندازی و نگهداری چه مواردی واقعاً تعیین‌کننده هستند.

چه زمانی کمپرسور رفت‌وبرگشتی انتخاب می‌شود؟

کمپرسور رفت‌وبرگشتی برای فشارهای بالا، دبی کم تا متوسط، گازهای فرایندی، گاز ترش، هیدروژن، نیتروژن، گاز سوخت و سرویس‌هایی که نسبت تراکم زیاد دارند انتخاب می‌شود. برخلاف کمپرسور اسکرو یا سانتریفیوژ، این تجهیز با حرکت رفت‌وبرگشتی پیستون گاز را فشرده می‌کند و می‌تواند فشارهای خروجی بالایی ایجاد کند. اما نگهداری آن پیچیده‌تر است و باید با لرزش، Pulsation، Packing، Valve و Lubrication جدی برخورد شود.

API 618 و محدوده تصمیم‌های خریدار

API 618 فقط یک استاندارد ساخت نیست؛ در بسیاری بندها از خریدار می‌خواهد تصمیم‌های مهم را در دیتاشیت مشخص کند. نوع Lubricated یا Non-lubricated Cylinder، تعداد Stage، Driver، Capacity Control، Instrumentation، Pulsation Study، Material و تست‌ها باید از ابتدا روشن باشد. اگر دیتاشیت ناقص باشد، سازنده فرضیات خود را اعمال می‌کند و بعداً در TBE اختلاف ایجاد می‌شود.

Pulsation و ارتعاش

رفت‌وبرگشتی بودن جریان باعث Pulsation می‌شود. اگر Bottle، Orifice، Pipe Support و مسیر لوله‌کشی درست طراحی نشود، فشار نوسانی و لرزش می‌تواند به نازل، تیوبینگ، Instrument و حتی سازه آسیب بزند. Pulsation Study و Mechanical Analysis برای پکیج‌های API 618 حیاتی است. در سایت نیز Supportها و فاصله Tie-in باید مطابق تحلیل نصب شوند.

Cylinder، Valve و Packing

Cylinder باید با گاز، فشار، دما و آلودگی سازگار باشد. Compressor Valveها قطعات مصرفی مهم هستند و خرابی آنها باعث افت ظرفیت و افزایش دما می‌شود. Packing و Rider Ring نیز روی نشتی، اصطکاک و نگهداری اثر دارند. در گازهای سمی یا قابل اشتعال، کنترل نشتی Packing و Vent/Distance Piece اهمیت ایمنی دارد.

Capacity Control و بهره‌برداری

کنترل ظرفیت می‌تواند با Clearance Pocket، Step Control، Speed Control یا روش‌های دیگر انجام شود. انتخاب روش به تغییرات دبی، فشار مکش، فشار تخلیه و مصرف انرژی بستگی دارد. اگر کمپرسور در بارهای پایین طولانی کار کند، دما، بار Rod و پایداری شیرها باید بررسی شود. اپراتور باید محدوده مجاز کارکرد را بداند.

Driver و سیستم‌های جانبی

Driver می‌تواند موتور الکتریکی، موتور گازسوز یا توربین باشد. Lube Oil System، Cooling Water، Intercooler/Aftercooler، Knock-out Drum، Filter و Control Panel بخشی از پکیج واقعی هستند. حذف هرکدام از Scope یا خرید جداگانه ناسازگار، ریسک راه‌اندازی را بالا می‌برد.

تست‌ها و مدارک

برای خرید باید Datasheet کامل، GA، P&ID، Pulsation Study، Lube Oil Datasheet، Driver Datasheet، ITP، NDT، Hydrotest، Mechanical Run Test و Performance Test در صورت الزام مشخص شود. برای Vesselهای جانبی، MDR و ASME Code مدارک مهم هستند. بدون این مدارک، تحویل پکیج در پروژه‌های نفت و گاز ناقص است.

مقایسه برندها

در مقایسه Ariel، Burckhardt، Howden، NEA، Siemens Energy یا Kobelco باید تجربه در گاز مشابه، تحلیل Pulsation، قطعات یدکی Valve/Packing، خدمات Commissioning و نرم‌افزار انتخاب بررسی شود. کمپرسور رفت‌وبرگشتی تجهیزی چرخه عمر محور است؛ قیمت اولیه تنها بخشی از تصمیم است.

انتخاب و محدوده کاربرد برای کمپرسور رفت و برگشتی

در ارزیابی پیشنهادها، مدارک مورد انتظار باید از ابتدا به فروشنده اعلام شود. برای کمپرسور رفت و برگشتی مدارکی مانند API 618، pulsation study، vibration، material certificates، performance data و manual نقش اصلی در پذیرش دارند. این مدارک باید با tag، serial، model code یا heat number همان کالای تحویلی قابل ردیابی باشند. مدرک عمومی یا کاتالوگ به تنهایی برای تحویل پروژه‌ای کافی نیست، زیرا نشان نمی‌دهد کالای واقعی همان مشخصات و همان آزمون‌های مورد انتظار را دارد.

ریسک‌هایی مانند ضربه مایع، pulsation، دمای discharge بالا، خرابی valve و lubrication نامناسب زمانی کاهش می‌یابند که خرید، مهندسی، کنترل کیفیت و بهره‌برداری یک معیار پذیرش مشترک داشته باشند. برای کمپرسور رفت و برگشتی بهتر است یک جدول کوتاه TBE تهیه شود که در آن گزینه‌های پیشنهادی از نظر استاندارد، ظرفیت، متریال، accessory، مدارک، تست، نصب و قطعات یدکی مقایسه شوند. اگر فروشنده جایگزین فنی پیشنهاد می‌کند، تفاوت‌ها باید کتبی و قابل بررسی باشند، نه صرفاً در توضیح شفاهی فروشنده.

در زمان تحویل و راه‌اندازی، کمپرسور رفت و برگشتی باید در شرایط واقعی سایت کنترل شود. این کنترل می‌تواند شامل بررسی پلاک، marking، ابعاد، سیگنال، فشار، دما، دبی، لرزش، نشتی، عملکرد alarm یا هر شاخص متناسب با همان تجهیز باشد. نتیجه تست اولیه، تنظیمات نهایی، قطعات یدکی و هر تغییر as-built باید در Data Book ثبت شود. این کار باعث می‌شود خریدهای بعدی و نگهداری تجهیز با داده قابل ردیابی انجام شود.

برای تکمیل عمق فنی این صفحه، لازم است کمپرسور رفت و برگشتی در چرخه کامل خرید تا بهره‌برداری دیده شود. داده‌های کلیدی مانند گاز، stage، pulsation، lube system، cooling، capacity control، valve و driver باید در RFQ، پیشنهاد فروشنده، مدارک تحویل و برنامه نگهداری یکسان باشند. اگر در هر مرحله یک نام یا عدد متفاوت ثبت شود، تیم سایت در زمان نصب یا تعمیرات با ابهام روبه‌رو می‌شود. بنابراین بهتر است نسخه نهایی دیتاشیت، مدارک API 618، pulsation study، vibration، material certificates، performance data و manual، نتیجه تست یا commissioning و فهرست قطعات یدکی در Data Book نگهداری شود. این کنترل ساده ریسک‌هایی مانند ضربه مایع، pulsation، دمای discharge بالا، خرابی valve و lubrication نامناسب را کاهش می‌دهد و باعث می‌شود خرید بعدی بر اساس تجربه واقعی پروژه انجام شود، نه صرفاً عنوان کالا یا حافظه افراد.
