خرید و تامین گیت ولو API 600 و API 602

تامین گیت ولو فولادی و فورج برای ایزولاسیون خطوط فرایندی؛ با کنترل نوع Wedge، Bonnet، Stem، کلاس، متریال و تست API 598.

شیرآلات صنعتیبررسی شرایط سرویستطبیق مشخصات سفارشاستعلام پروژه‌ای

تصویر برای معرفی گروه محصول است؛ مشخصات و اقلام همراه باید با پیشنهاد همان سفارش تطبیق داده شوند.

شیر کشویی را برای ایزولاسیون انتخاب کنید، نه تنظیم مداوم دبی

گیت ولو یا شیر کشویی معمول برای کار در حالت کاملاً باز یا بسته انتخاب می‌شود. اگر هدف تنظیم مداوم جریان است، طراحی دیگری باید بررسی شود. در سفارش، نوع گوه، بونت، ساقه، جنس تریم و اختلاف فشار هنگام بازشدن را کنار سایز و کلاس مشخص کنید.

در تعویض شیر موجود، طول Face-to-Face یا End-to-End، نوع اتصال و فضای لازم برای حرکت ساقه اهمیت دارند. برای مدل Rising Stem، ارتفاع شیر در حالت باز را از نقشه سازنده بگیرید. انتخاب فلکه یا گیربکس باید با نیروی موردنیاز، تعداد دور و دسترسی اپراتور سازگار باشد؛ سایز بزرگ به‌تنهایی مشخصات گیربکس را تعیین نمی‌کند.

استانداردهایی که باید در استعلام ذکر شوند

ذکر استاندارد در RFQ نباید کلی و مبهم باشد. استاندارد ساخت، تست، مدارک، متریال و اتصال هرکدام اثر متفاوتی روی قیمت و پذیرش کالا دارد.

  • API 600 برای Gate Valve فولادی فلنجی و BW
  • API 602 برای شیرهای فولادی فشرده در دامنه تعریف‌شده استاندارد
  • ASME B16.34 برای Rating و بدنه
  • API 598 برای آزمون‌های Shell، Seat و Backseat در موارد قابل اعمال طبق سفارش و طراحی
  • ASME B16.10 برای Face-to-Face

مرجع دامنه استاندارد فشار–دما: معرفی رسمی ASME B16.34. این معرفی جایگزین جدول‌ها و الزامات ویرایش قراردادی یا محدودیت‌های مدل سازنده نیست.

انتخاب نوع و پیکربندی مناسب

برای گیت ولو صنعتی یک مدل واحد برای همه پروژه‌ها وجود ندارد. گزینه درست باید با شرایط نصب، روش بهره‌برداری، ریسک تعمیرات و محدودیت‌های پروژه انتخاب شود.

  • Solid Wedge برای سرویس‌های عمومی و دمای متعادل
  • Flexible Wedge برای کاهش گیرکردن در دمای متغیر
  • Pressure Seal Bonnet برای کلاس و دمای بالا
  • OS&Y Rising Stem برای مشاهده وضعیت باز/بسته
  • Gear Operated برای سایزهای بزرگ

برندها و سازندگان قابل بررسی برای گیت ولو صنعتی

در استعلام‌های پروژه‌ای، برند باید با Vendor List، کشور سازنده مجاز، مدارک اصالت، زمان تحویل و سطح خدمات پس از فروش هماهنگ باشد. برای این گروه محصول، برندها/سازندگان زیر معمولاً در بازار صنعتی یا وندورلیست‌های پروژه‌ای قابل بررسی هستند: Velan، Crane، Neway، KITZ، OMB، Bonney Forge. ذکر این نام‌ها به معنی موجودی دائمی یا تأیید همه مدل‌ها نیست؛ هر سفارش باید با Datasheet و مدارک همان پروژه کنترل شود.

کاربردهای صنعتی و مرزهای استفاده

کاربردهای زیر برای گیت ولو صنعتی رایج هستند، اما همین محصول در هر سرویس رفتار متفاوتی دارد. اگر گیت ولو صنعتی در واحد پتروشیمی، کارخانه فولاد یا پکیج Utility استفاده شود، معیارهایی مانند متریال، برند، تست و زمان تحویل باید متناسب با همان محیط بازتعریف شود.

  • ایزولاسیون خطوط اصلی پالایشگاه و پتروشیمی
  • بخار، آب آتش‌نشانی و Utility با افت فشار کم
  • نقاط ورودی/خروجی تجهیزات که معمولاً کاملاً باز یا بسته‌اند

مدارک و کنترل کیفیت پیش از تحویل

در خرید پروژه‌ای، تحویل فیزیکی کالا بدون مدارک قابل ردیابی کافی نیست. مدارک زیر باید قبل از حمل یا حداکثر هنگام تحویل کنترل شوند:

  • MTC Body/Bonnet/Wedge/Stem
  • API 598 Test Certificate
  • ابعاد Face-to-Face و وزن تقریبی
  • Painting، Marking و Packing List

در سفارش‌های حساس، بهتر است قبل از صدور PO یک جدول Technical Compliance تهیه شود. در این جدول، هر بند دیتاشیت با پیشنهاد فروشنده مقایسه می‌شود و موارد انحرافی قبل از پرداخت یا حمل مشخص می‌گردد. این کار برای گیت ولو صنعتی به‌خصوص زمانی مهم است که چند برند یا چند کشور سازنده هم‌زمان پیشنهاد داده شده‌اند.

خطاهای رایج که باعث خرید نامطمئن می‌شوند

  • استفاده از گیت ولو برای Throttling طولانی
  • عدم توجه به Flexible Wedge در سرویس دمایی
  • انتخاب Handwheel برای سایز بزرگ بدون بررسی گشتاور
  • تطبیق ندادن Face-to-Face با فضای نصب

در خرید گیت ولو صنعتی بخش زیادی از اختلاف قیمت از همین جزئیات ناشی می‌شود. پیشنهادی که برای گیت ولو صنعتی مدارک کامل، تست معتبر و برند قابل ردیابی ارائه می‌کند، با پیشنهادی که فقط نام کلی محصول را نوشته است هم‌سطح نیست و نباید صرفاً عددی مقایسه شود.

نحوه ارزیابی برند و پیشنهاد فنی

برندهای مطرح معمولاً مزیت‌هایی مثل دیتاشیت دقیق‌تر، قطعات یدکی قابل پیگیری‌تر، تست‌های استانداردتر و سابقه نصب در پروژه‌های مشابه دارند. با این حال، حتی برند شناخته‌شده نیز بدون تطبیق مدل و مدارک کافی نیست. برای گیت ولو صنعتی، نام برند باید کنار Model/Type، کشور ساخت، گواهی‌ها، Lead Time و شرایط تأمین قطعات بررسی شود.

در بازار ایران، گیت ولو صنعتی ممکن است با چند سطح کیفیت، چند منشأ تأمین و چند نوع مدرک عرضه شود. پیشنهاد فنی باید روشن کند کالای پیشنهادی Original است یا معادل، چه تست‌هایی برای همین گیت ولو صنعتی انجام شده، بسته‌بندی چگونه است و در صورت نیاز به TPI چه Hold Pointهایی قابل اجراست.

راهنمای عمیق انتخاب Gate Valve برای کاربر خط و تیم تعمیرات

در گیت ولو، مهم‌ترین نکته این است که تجهیز برای ایزولاسیون کامل طراحی شده است، نه کنترل دبی. اگر بهره‌بردار عادت داشته باشد شیر را نیمه‌باز نگه دارد، جریان از زیر Wedge با سرعت بالا عبور می‌کند و باعث فرسایش Seat، لرزش Wedge و نشتی تدریجی می‌شود. بنابراین در دستورالعمل بهره‌برداری باید مشخص شود Gate Valve یا کاملاً باز است یا کاملاً بسته. اگر پروژه به کنترل جریان نیاز دارد، Globe Valve یا Control Valve باید بررسی شود.

نوع Wedge در سرویس‌های دمایی اهمیت ویژه دارد. Solid Wedge برای سرویس‌های عمومی ساده‌تر است، اما در بخار یا خطوطی که سیکل حرارتی دارند، Flexible Wedge می‌تواند خطر گیرکردن ناشی از انبساط حرارتی را کاهش دهد. در کلاس‌های بالا، Pressure Seal Bonnet به‌جای Bolted Bonnet رایج می‌شود، چون فشار داخلی به آب‌بندی Bonnet کمک می‌کند. این انتخاب‌ها مستقیماً روی قیمت، وزن، تعمیرپذیری و زمان تحویل اثر دارند.

در بازرسی گیت ولو، فقط تست Seat کافی نیست. Backseat Test در صورت کاربرد، کنترل Stem، وضعیت Thread، یکنواختی حرکت Handwheel، Marking کلاس و متریال، Face-to-Face و کیفیت سطح فلنج باید بررسی شود. اگر ولو قرار است Gearbox داشته باشد، نسبت گیربکس و تعداد دور تا بازشدن کامل باید برای بهره‌بردار قابل قبول باشد. در خطوط بزرگ، نداشتن Gearbox مناسب می‌تواند عملاً بهره‌برداری را سخت یا ناایمن کند.

برای برندهایی مانند Velan، Crane، Neway، KITZ، OMB یا Bonney Forge باید دقیقاً سری محصول، استاندارد ساخت، کشور سازنده، متریال Trim و مدارک تست مقایسه شود. یک Gate Valve API 600 از دو برند متفاوت ممکن است از نظر ضخامت بدنه، کیفیت Trim، طراحی Wedge و جزئیات Bonnet تفاوت داشته باشد. در TBE پروژه، بهتر است جدول مقایسه فنی شامل Wedge Type، Bonnet، Trim No، Seat Leakage و مدارک قابل ارائه باشد. Backseat را مجوز تعویض پکینگ زیر فشار تلقی نکنید؛ تعمیرات تابع روش ایمن مصوب و دستورالعمل سازنده است.

برای مقایسه قیمت گیت ولو چه مواردی باید یکسان باشند؟

دو شیر هم‌سایز با تریم، بونت یا روش اتصال متفاوت، الزاماً یک قلم خرید نیستند. برای جایگزینی، هزینه و محدودیت تغییرات نصب را نیز مستقل از قیمت شیر بررسی کنید.

اگر بین شیر قطع و وصل و تنظیم جریان تصمیم می‌گیرید، مقایسه گیت ولو و گلوب ولو را بخوانید. برای محدودیت‌های انتخاب گوه نیز راهنمای طراحی گوه انعطاف‌پذیر در دسترس است.
