تامین پمپ صنعتی بر اساس استاندارد، عملکرد و سرویس

پمپ قلب تپنده هر واحد فرایندی است. اختلال در یک پمپ کلیدی می‌تواند کل یک خط تولید را متوقف کند. به همین دلیل، تامین پمپ صنعتی فراتر از خرید یک تجهیز است — نیازمند درک عمیق کاربرد فرایندی (Process Service)، شرایط عملیاتی (Operating Conditions)، الزامات استاندارد (API/ANSI/ISO) و گزینه‌های متریال است.

شرکت پیشرو تجهیز فرتاک با تخصص در تامین تجهیزات روتاری، پمپ‌های صنعتی را بر اساس Datasheet دقیق پروژه، Vendor List کارفرما و الزامات فنی (API 610، API 675، ASME B73.1، ISO 13709) تامین می‌کند. هر سفارش با Performance Test Curve، Hydrostatic Test Certificate، Material Test Certificate و در صورت نیاز Witness Inspection تحویل می‌شود.

۶ خانواده اصلی پمپ‌های قابل تامین

  • سانتریفیوژ API 610 — استاندارد مرجع برای پمپ‌های نفت و گاز. شامل کدهای OH1 (Overhung Single Stage)، OH2 (Foot Mounted)، OH3 (Vertical)، BB1 (Axially Split)، BB2 (Radially Split)، BB3 (Multistage)، BB5 (Barrel)، VS1-VS7 (Vertical Suspended).
  • سانتریفیوژ ANSI / ASME B73.1 — استاندارد آمریکایی برای پمپ‌های فرایندی شیمیایی، ابعاد استاندارد قابل تعویض بین برندها.
  • دوزینگ (Metering) — API 675 — Diaphragm، Plunger، Hydraulic Diaphragm برای تزریق دقیق مواد شیمیایی، پلیمر، کاتالیست با دقت ±1٪.
  • طبقاتی عمودی (Vertical Multistage) — برای فشار بالا با فلو متوسط مثل آبرسانی، بویلر Feedwater، Cleaning. برندهای CR گراندفوس، CRN، Lowara.
  • Slurry و دو فاز (Two-Phase) — برای انتقال مخلوط مایع-جامد در فولاد، معدن، سیمان. متریال‌های مقاوم به سایش مثل High Chrome، Rubber Lined.
  • Positive Displacement — Screw، Gear، Lobe، Diaphragm برای سیالات ویسکوز یا دقیق. کاربرد در روغن سنگین، عسل، خمیر، چسب.

فرآیند ۷ مرحله‌ای تامین پمپ صنعتی

  1. دریافت Datasheet و RFQ — حداقل شامل Flow، Head، NPSHa، Service، Material، Standard.
  2. Pump Selection — کارشناس از نرم‌افزار سازنده برای انتخاب مدل دقیق با حداکثر Efficiency استفاده می‌کند.
  3. Mechanical Seal Plan — انتخاب Seal Plan مطابق API 682 (Plan 11، 23، 32، 52، 53A...).
  4. سورسینگ از منابع برند — استعلام از نمایندگی‌های معتبر.
  5. پیشنهاد فنی-تجاری — Quotation با Performance Curve، Cross Section، Material List.
  6. عقد قرارداد و ساخت — پیگیری ساخت، Hydrostatic Test، Performance Test (در صورت Witness).
  7. FAT، حمل و SAT — Factory Acceptance Test، حمل و در صورت قرارداد Site Acceptance Test.

چه پروژه‌هایی به این خدمت نیاز دارند؟

  • پروژه‌های فرآیندی نفت و گاز (Crude Transfer، Reflux، Boiler Feedwater)
  • واحدهای پتروشیمی (پمپ‌های polymer، catalyst، quench)
  • صنایع فولاد و معدن (Slurry، Mill Discharge، Cooling)
  • تاسیسات نیروگاهی (BFW، Condensate Extraction، Circulating Water)
  • تصفیه آب و فاضلاب (Raw Water، RO Booster، Dosing)
  • تامین قطعات یدکی برای تعمیرات اساسی و اورهال

چرا پیشرو تجهیز فرتاک برای تامین پمپ؟

  • تخصص API 610 — تیم آشنا با کدهای پمپ، Seal Plan ها و الزامات NACE.
  • دسترسی به برندهای OEM — KSB، Sulzer، Flowserve و سایر برندهای مرجع.
  • تامین قطعات یدکی — حتی برای پمپ‌های قدیمی با Part Number.
  • پشتیبانی Performance Test — حضور در تست FAT و SAT.
  • مدارک کامل فنی — Performance Curve، MTC، Hydrotest Cert.

سوالات متداول

API 610 چیست و چرا برای پمپ‌های نفت و گاز الزامی است؟

API 610 (آخرین نسخه: 12th Edition) استاندارد بین‌المللی پمپ‌های سانتریفیوژ برای صنایع نفت، گاز و پتروشیمی است. این استاندارد الزامات طراحی، متریال، تست هیدرواستاتیک، Mechanical Seal، Baseplate و Coupling را تعریف می‌کند. پمپ‌های مطابق API 610 با کدهای OH1، OH2، BB2، BB3، VS1 و... دسته‌بندی می‌شوند.

برای استعلام پمپ چه اطلاعاتی لازم است؟

Datasheet پمپ شامل: Flow rate (m³/h یا GPM)، Total Dynamic Head (TDH)، NPSHa، Suction/Discharge size، Service (سیال + دما + خصوصیات)، Specific Gravity، Viscosity، متریال (Casing، Impeller، Shaft)، نوع Mechanical Seal، Driver type (Motor/Turbine)، استاندارد (API 610/ANSI/...)، Hazardous Area Class.

تفاوت Centrifugal Pump و Positive Displacement چیست؟

Centrifugal Pump با چرخش پروانه (Impeller) سیال را شتاب می‌دهد، برای فلو بالا و فشار متوسط مناسب است (مثل آب، نفت سبک). Positive Displacement (Reciprocating، Gear، Screw، Diaphragm) با حرکت مکانیکی حجم ثابت سیال را جابجا می‌کند، برای فلو پایین و فشار بسیار بالا یا سیالات ویسکوز (مثل دوزینگ شیمیایی، روغن سنگین) مناسب است.

NPSH چیست و چرا مهم است؟

Net Positive Suction Head (NPSH) فشار خالص در مکش پمپ است. NPSHa (Available) توسط سیستم تامین می‌شود و NPSHr (Required) توسط پمپ نیاز است. اگر NPSHa کمتر از NPSHr باشد، Cavitation (تشکیل حباب) اتفاق می‌افتد که باعث خوردگی پروانه و کاهش عمر پمپ می‌شود. قانون طلایی: NPSHa حداقل ۰.۵ تا ۱ متر بیشتر از NPSHr.

Mechanical Seal بهتر است یا Gland Packing؟

Mechanical Seal: نشتی نزدیک به صفر، عمر طولانی، نگهداری کم، اما گران‌تر و نیاز به Flush Plan. مناسب برای سیالات سمی، گران و دما بالا. Gland Packing: ارزان، تعمیر آسان، نشتی کنترل‌شده دارد. مناسب برای آب، سیال غیرسمی. در پروژه‌های API 610 معمولاً Mechanical Seal دوگانه (API 682 Plan) الزامی است.

آیا قطعات یدکی پمپ‌های قدیمی هم تامین می‌کنید؟

بله. قطعات یدکی شامل Impeller، Casing Wear Ring، Shaft، Bearing، Mechanical Seal، Coupling، Baseplate و... برای پمپ‌های موجود قابل تامین است. برای تامین دقیق، Part Number از روی Nameplate پمپ، Serial Number یا نقشه سازنده ضروری است.

درخواست استعلام (RFQ)

برای دریافت پیشنهاد فنی-تجاری دقیق، Datasheet پمپ به همراه Vendor List پروژه را به واحد بازرگانی ارسال کنید. کارشناس روتاری ما پس از Pump Selection، گزینه‌های تامین به همراه Performance Curve و زمان تحویل را اعلام می‌کند.
