# تحقیق قیمت — بایگانی، نه برنامه انتشار

۱۲ رکورد مرحله اولیه حفظ شده‌اند. قیمت و نرخ مربوط به ۲۰۲۶-۰۹-۱۹ هستند، نه نرخ زنده. فایل CSV نشانی‌های پیشنهادیِ صفحات حذف‌شده را در ستون page دارد؛ این نشانی‌ها منتشر نشده‌اند و مقصد فعال محسوب نمی‌شوند. ساخت صفحات مستقل و ابزار تولید طبق درخواست کاربر حذف شده است. این پوشه داده داخلی است، در سایت لینک نشده و در Apache با Require all denied محافظت شده است. برای هر میزبان غیر Apache دسترسی را جداگانه ببندید یا آن را از بسته انتشار حذف کنید.
