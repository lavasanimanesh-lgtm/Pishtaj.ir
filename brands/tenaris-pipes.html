تامین و سورسینگ تناریس Tenaris

راهنمای سورسینگ لوله‌های Tenaris شامل OCTG، Line Pipe، Seamless Pipe و لوله‌های نیروگاهی/آلیاژی بدون ادعای نمایندگی رسمی.

تذکر حقوقی:

این صفحه ادعای نمایندگی رسمی یا موجودی دائمی برند Tenaris ندارد و صرفاً راهنمای سورسینگ پروژه‌ای است.

دامنه محصولات قابل بررسی

Tenaris در بازار جهانی لوله‌های OCTG، Line Pipe، Seamless Pipe، Premium Connections و لوله‌های خاص انرژی شناخته می‌شود. در پروژه‌های صنعتی ایران، نام Tenaris معمولاً در لوله‌های API 5L، A106، A335 یا کاربردهای نفت و گاز مطرح می‌شود. اما خرید باید با Grade، PSL، روش ساخت، MTC و کشور سازنده کنترل شود.

Line Pipe و OCTG

Line Pipe برای انتقال سیالات و OCTG برای حفاری و تولید چاه استفاده می‌شود. این دو نباید به جای هم استفاده شوند. برای API 5L، PSL1/PSL2، Sour Service، Charpy و Coating مهم است. برای OCTG، API 5CT، Connection، Drift و Collapse/ Burst مطرح می‌شود.

مدارک و Traceability

Heat Number، MTC 3.1/3.2، Test Report، Hydrotest، NDT، Coating Report و Marking باید با خود لوله تطبیق داده شود. در خریدهای بزرگ، عکس بسته‌بندی و Release Note قبل از حمل ریسک اختلاف را کم می‌کند.

عدم ادعای نمایندگی

این صفحه نمایندگی رسمی Tenaris نیست. هدف، راهنمای فنی سورسینگ و تطبیق لوله‌های Tenaris یا معادل‌های تاییدشده با Spec پروژه است.
