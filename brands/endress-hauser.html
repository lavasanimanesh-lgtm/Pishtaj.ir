Pressure و Differential Pressure

در فشار، تجهیزاتی مانند pressure transmitter و differential pressure transmitter برای اندازه‌گیری فشار، سطح هیدرواستاتیک، فیلتر differential، flow با primary element و monitoring پمپ‌ها استفاده می‌شوند. انتخاب range، overpressure، diaphragm material، fill fluid، process connection، remote seal، capillary، accuracy و SIL requirement اهمیت دارد. اگر سیال خورنده، داغ، ویسکوز، crystallizing یا sanitary باشد، diaphragm seal و متریال مناسب باید بررسی شود.

در DP flow، transmitter به‌تنهایی کافی نیست؛ orifice plate، meter run، impulse line، manifold، tapping، temperature/pressure compensation و installation details روی دقت اثر دارند. اگر DP transmitter برای سطح مخزن تحت فشار استفاده می‌شود، wet leg/dry leg، density، capillary length و temperature effect باید دیده شود. در خرید جایگزین، span، LRV/URV، mounting و protocol باید با سیستم کنترل موجود سازگار باشد.

Flow؛ Promag، Promass و فناوری‌های مختلف

در خانواده دبی، Endress+Hauser با magnetic flowmeter، Coriolis، vortex، ultrasonic و thermal mass در کاربردهای مختلف مطرح است. برای magmeter، رسانایی سیال، lining، electrode، grounding و installation اهمیت دارد. برای Coriolis، mass flow، density، pressure drop، vibration، دوغاب یا گاز دو فازی و متریال باید بررسی شود. برای vortex، بخار، گاز، مایعات تمیز، Reynolds، طول مستقیم و جبران فشار/دما مطرح می‌شود.

یک اشتباه رایج، جایگزینی فناوری‌ها بدون تحلیل سرویس است. اگر سیال رسانا نیست، magmeter مناسب نیست. اگر بخار مرطوب و جریان ناپایدار است، vortex ممکن است reading چالش‌دار داشته باشد. اگر دقت بالا لازم است اما افت فشار قابل قبول نیست، انتخاب Coriolis باید با احتیاط انجام شود. بنابراین RFQ باید فناوری پیشنهادی و دلیل انتخاب آن را مشخص کند.

Level و آنالایزرها

در سطح، رادار غیرتماسی، guided wave radar، ultrasonic، capacitance، hydrostatic و point level هرکدام کاربرد خاص دارند. برای مخازن دارای foam، dust، vapor، agitation، nozzle بلند یا dielectric پایین، انتخاب سطح‌سنج باید با جزئیات vessel انجام شود. برای point level، تجهیزاتی مانند vibration fork در برخی سرویس‌ها مطرح می‌شود، اما چسبندگی، density، دما و فشار باید بررسی شود. اگر سطح‌سنج برای safety یا overfill prevention استفاده می‌شود، مدارک SIL و proof test نیز اهمیت پیدا می‌کند.

در آنالایزرهای مایعات، pH، conductivity، dissolved oxygen، turbidity، chlorine و پارامترهای کیفیت آب مطرح هستند. سنسور، ترانسمیتر، کابل، holder، cleaning system، calibration solution و شرایط نمونه‌برداری همگی در عملکرد اثر دارند. در خرید، فقط نام analyzer کافی نیست؛ باید process temperature، pressure، chemical compatibility، sample condition و maintenance interval مشخص شود.
