تامین و سورسینگ شیرآلات KITZ

راهنمای سورسینگ شیرآلات KITZ شامل Ball، Gate، Globe، Check و Butterfly Valve برای سرویس‌های صنعتی، بدون ادعای نمایندگی رسمی.

این صفحه ادعای نمایندگی رسمی یا موجودی دائمی برند KITZ Valves ندارد. هدف، راهنمای فنی برای سورسینگ، استعلام و تطبیق با وندورلیست پروژه است.

دامنه شیرآلات قابل بررسی

KITZ در بازار شیرآلات صنعتی با محصولات Ball، Gate، Globe، Check، Butterfly و برخی Actuated Valveها شناخته می‌شود. در پروژه‌های نفت، گاز، پتروشیمی، آب، Utility و صنایع عمومی، انتخاب KITZ باید با استاندارد ساخت، متریال، کلاس فشار، نوع اتصال، Seat و سرویس هماهنگ شود.

مدل، متریال و استاندارد

در شیرآلات، نام برند کافی نیست. باید مشخص شود شیر مطابق API 6D، API 600، API 602، API 609، ASME B16.34 یا استاندارد دیگر است. متریال WCB، CF8M، Bronze، Stainless یا Alloy، نوع Seat، Trim، Fire Safe، NACE و End Connection باید در دیتاشیت بیاید.

کنترل اصالت و مدارک

برای شیرآلات وارداتی، پلاک، Marking، Casting/Forging Mark، MTC، Test Report، Packing و Country of Origin باید کنترل شود. در پروژه‌های حساس، Seat Test و Shell Test مطابق API 598 یا استاندارد مربوط باید ارائه شود.

عبارت حقوقی مهم

این صفحه به معنی نمایندگی رسمی KITZ نیست. هدف، راهنمای خرید و سورسینگ شیرآلات KITZ یا محصولات قابل تطبیق با وندورلیست پروژه است. هر سفارش باید با مدارک و تایید فنی کارفرما انجام شود.

KITZ در شیرآلات صنعتی و ساختمانی سنگین

KITZ از برندهای شناخته‌شده ژاپنی در حوزه شیرآلات صنعتی است و در پروژه‌ها معمولاً برای ball valve، gate valve، globe valve، check valve، butterfly valve و برخی کاربردهای utility یا process مطرح می‌شود. در خرید برندمحور KITZ، باید تفاوت میان شیر عمومی، شیر صنعتی فرایندی و شیر مناسب سرویس خاص روشن باشد. جنس بدنه، کلاس فشاری، نوع اتصال، trim، seat، استاندارد تست و سرویس سیال تعیین می‌کند آیا یک مدل برای آب، بخار، گاز، روغن، هوا یا سیال شیمیایی قابل قبول است یا خیر.

در RFQ نباید فقط سایز و برند نوشته شود. لازم است استاندارد طراحی، pressure class، end connection، body material، trim/seat material، operation، fire-safe requirement، NACE requirement، test standard، temperature range و مدارک مورد نیاز مشخص شود. برای پروژه‌های دارای وندورلیست، باید روشن شود KITZ برای همان خانواده تجهیز و همان سرویس پذیرفته شده است یا نیاز به approval جداگانه دارد.

Ball، Gate، Globe و Check Valve

Ball valve برای on/off سریع و افت فشار کم استفاده می‌شود، اما seat material و fire-safe design در سرویس‌های هیدروکربنی اهمیت دارد. Gate valve برای isolation در خطوط بزرگ کاربرد دارد، ولی برای throttling مناسب نیست و نیمه‌باز کار کردن می‌تواند به gate و seat آسیب بزند. Globe valve برای throttling بهتر است، اما افت فشار بیشتری دارد. Check valve نیز باید بر اساس جهت جریان، احتمال ضربه قوچ، minimum flow و نصب افقی/عمودی انتخاب شود.

در شیرهای برنزی، برنجی، چدنی، کربن استیل یا استنلس، محدوده دما و فشار کاملاً متفاوت است. یک شیر ظاهراً مشابه KITZ ممکن است برای utility مناسب باشد اما برای فرایند فشار بالا یا سرویس خورنده مناسب نباشد. بنابراین مقایسه مدل‌ها باید با datasheet و pressure-temperature rating انجام شود.

مدارک، تست و اصالت

مدارک قابل درخواست شامل datasheet، certificate of conformity، pressure test report، material certificate برای pressure-containing parts در صورت الزام، fire-safe certificate در صورت نیاز، manual و packing list است. برای برخی پروژه‌ها، API 598، ISO 5208، ASME B16.34، API 607 یا استانداردهای مشابه مطرح می‌شود. اگر شیر برای محیط حساس خریداری می‌شود، test و certificate باید در RFQ صریحاً درخواست شود.

در تحویل، marking روی body، سایز، کلاس، جهت جریان، متریال، operator، flange standard و بسته‌بندی کنترل می‌شود. اگر شیر gear operator یا actuator دارد، torque، limit switch، handwheel و accessoryها باید با سفارش تطبیق داده شوند. برای شیرهای flanged، face finish و استاندارد فلنج باید با خط پایپینگ هماهنگ باشد.

جایگزینی و پروژه‌های maintenance

در تعمیرات، ممکن است هدف جایگزینی یک شیر قدیمی KITZ باشد. در این حالت عکس پلاک، face-to-face، end connection، handwheel/gear، ارتفاع نصب، جهت flow و محدودیت فضای اطراف باید بررسی شود. اگر مدل قدیمی discontinued شده، جایگزین باید از نظر ابعاد، rating، متریال و استاندارد تست مقایسه شود. صرف نزدیک بودن سایز و کلاس کافی نیست، چون face-to-face یا operator ممکن است متفاوت باشد.

نکات تکمیلی برای سرویس‌های بخار، آب و هیدروکربن

در سرویس بخار، انتخاب شیر KITZ یا هر برند دیگر باید با فشار، دما، condensate، نوع operation و استاندارد خط هماهنگ باشد. استفاده از seat نامناسب یا کلاس پایین‌تر می‌تواند باعث نشتی و فرسایش شود. در خطوط آب خنک‌کننده یا آتش‌نشانی، خوردگی، رسوب، ضربه قوچ و امکان باز و بسته شدن پس از مدت طولانی اهمیت دارد. در سرویس‌های هیدروکربنی، fire-safe، anti-static design، fugitive emission و سازگاری packing با سیال باید بر اساس استاندارد پروژه بررسی شود.

برای utilityهای ساده، ممکن است مدل‌های عمومی اقتصادی باشند، اما اگر همان مدل به اشتباه در process line حساس استفاده شود، ریسک فنی بالا می‌رود. بنابراین لازم است هر درخواست خرید، service code یا line class داشته باشد. line class مشخص می‌کند چه متریال، rating، end connection، gasket و bolting مجاز است. اگر فروشنده فقط به برند و سایز پاسخ دهد، تیم فنی باید قبل از سفارش، انطباق با line class را کنترل کند.

کنترل قطعات یدکی و تعمیرات

برای شیرهای KITZ، قطعاتی مانند seat، gasket، packing، stem، handwheel، gear و repair kit باید با مدل و سایز دقیق تطبیق داده شود. در تعمیرات، استفاده از gasket یا packing عمومی ممکن است در ابتدا کار کند اما در دمای بالا یا سرویس شیمیایی دچار نشتی شود. اگر valve در محل سخت‌دسترس نصب شده، کیفیت قطعه یدکی اهمیت بیشتری دارد چون دوباره‌کاری هزینه زیادی دارد. در shutdownها بهتر است repair kit قبل از توقف خط آماده و با serial یا model تجهیز تطبیق داده شود.

در بازرسی ورودی، valve باید از نظر آسیب حمل، سلامت flange face، عملکرد handwheel/gear، تمیزی داخل، marking، جهت جریان و بسته‌بندی کنترل شود. برای شیرهای رزوه‌ای، نوع thread باید با استاندارد پروژه هماهنگ باشد. اگر adaptor غیرضروری در سایت استفاده شود، هم نقطه نشتی اضافه می‌شود و هم امکان رد شدن بازرسی وجود دارد.

اگر برند جایگزین برای KITZ پیشنهاد می‌شود، باید face-to-face، pressure-temperature rating، متریال، استاندارد تست و سابقه کاربرد مشابه مقایسه شود. جایگزین فقط وقتی قابل قبول است که تفاوت‌ها در TBE شفاف و توسط کارفرما تایید شود.

تکمیل ارزیابی فنی KITZ پیش از سفارش

برای اینکه پیشنهاد KITZ با پیشنهادهای جایگزین قابل مقایسه باشد، بهتر است جدول TBE شامل استاندارد طراحی، کلاس فشاری، متریال بدنه، متریال seat، نوع stem، روش operation، تست نشتی، مدارک و lead time باشد. اگر شیر برای سرویس بخار یا هیدروکربن استفاده می‌شود، دمای کاری و fire-safe requirement باید جداگانه کنترل شود. اگر شیر برای آب یا utility است، خوردگی، رسوب و امکان باز و بسته شدن پس از دوره طولانی عدم استفاده مهم است. این تفکیک مانع می‌شود یک مدل عمومی در خط حساس نصب شود.

در زمان تحویل، بهتر است هر شیر با tag یا line class مشخص شود و مدارک همراه همان بسته نگهداری گردد. اگر پروژه چند سایز و چند کلاس دارد، مخلوط شدن شیرهای مشابه در انبار خطر جدی ایجاد می‌کند. کنترل marking روی بدنه، direction، flange face، handwheel، gear و بسته‌بندی قبل از انتقال به سایت نصب باید انجام شود. برای شیرهای رزوه‌ای یا socket weld، نوع اتصال و استاندارد thread یا socket باید با piping specification مطابقت داشته باشد تا در سایت از تبدیل‌های غیرضروری استفاده نشود.

اگر تجهیز برای shutdown خریداری می‌شود، بهتر است یک روز قبل از توقف خط، fit-up و مدارک روی میز کنترل شوند؛ چون در زمان shutdown فرصت اصلاح سفارش اشتباه وجود ندارد. این روش ساده، ریسک تأخیر راه‌اندازی را کاهش می‌دهد.

برای عبور از کنترل نهایی، پیشنهاد می‌شود قبل از صدور سفارش، یک عکس از نمونه marking مورد انتظار، استاندارد تست و قالب مدارک تحویلی از فروشنده دریافت شود. این کار مخصوصاً زمانی مفید است که شیرها برای چند line class مختلف خریداری می‌شوند و احتمال اختلاط کلاس یا متریال در انبار وجود دارد.

در صورت نیاز به actuator در آینده، torque مورد نیاز و امکان نصب bracket نیز از ابتدا بررسی شود.

در سفارش‌های پروژه‌ای KITZ، هماهنگی متریال شیر با gasket و bolting فلنج نیز باید کنترل شود. اگر کلاس فشار، facing یا دمای کاری با اقلام اتصال هماهنگ نباشد، نشتی ممکن است به اشتباه به کیفیت شیر نسبت داده شود در حالی که ریشه مشکل در انتخاب مجموعه فلنجی است. بنابراین بررسی valve، gasket و stud bolt باید همزمان انجام شود.

این هماهنگی باید پیش از صدور سفارش نهایی مکتوب شود.
