برای API 5L، Grade، PSL، Sour Service و Coating مهم است. برای A335، گریدهای P11/P22/P91 و PWHT/Hardness مطرح می‌شود. برای A333، Impact Test و MDMT مهم است. بنابراین فقط نام Vallourec کافی نیست و باید استاندارد و سرویس دقیق معلوم باشد.

مدارک و تحویل

MTC، Heat Number، Hydro/NDT، Impact، Coating Report، Marking و Packing باید کنترل شود. در پروژه‌های حساس، TPI و Release Note قبل از حمل ارزش زیادی دارد. لوله‌های بدون Traceability، حتی اگر ظاهراً برند باشند، ریسک پذیرش دارند.
