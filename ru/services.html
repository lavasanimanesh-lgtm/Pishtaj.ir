Услуги поставки

Те же шесть направлений, что на персидском сайте — от ЗИП до консолидированного проектного пакета.

Трубопроводы и фланцы

Бесшовные A106 / A333 / API 5L, фланцы ASME B16.5, фитинги, прокладки и крепёж с сертификатами завода.

Промышленная арматура

Задвижки API 600, шаровые API 6D, обратные, дисковые, регулирующие клапаны, PSV и приводы.

Электрика

РУ НН/СН, ACB/MCCB, трансформаторы, ПЧ, ИБП, ПЛК и пакеты MCC.

КИП

Rosemount 3051, расход, уровень, температура, газообнаружение и регулирующие клапаны.

Насосы

API 610, ANSI process, дозирующие и многоступенчатые насосы, торцевые уплотнения и ЗИП.

Котлы и пар

Жаротрубные и водотрубные котлы, горелки, конденсатоотводчики, теплообменники и сосуды.
