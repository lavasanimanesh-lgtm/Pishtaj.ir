Services de fourniture

Les six mêmes domaines que le site persan — de la pièce de rechange au package projet consolidé.

Tuyauterie et brides

Sans soudure A106 / A333 / API 5L, brides ASME B16.5, raccords, joints et boulonnerie avec certificats usine.

Vannes industrielles

Vanne à opercule API 600, boisseau API 6D, clapet, papillon, vannes de régulation, PSV et actionneurs.

Électrique

Tableaux BT/MT, ACB/MCCB, transformateurs, VFD, UPS, API et packages MCC.

Instrumentation

Rosemount 3051, débit, niveau, température, détection gaz et vannes de régulation.

Pompes

API 610, process ANSI, dosage et multi-étages, plus garnitures mécaniques.

Chaudières et vapeur

Chaudières tubes de fumée et d’eau, brûleurs, purgeurs, échangeurs et appareils à pression.
