# گزارش فاز Performance و اندازه‌گیری سئو
**تاریخ:** ۲۰۲۶-۰۸-۰۴  
**دامنه:** سایت عمومی؛ بدون تغییر مستقیم در منطق `crm/` و `api/`

## هدف فاز
بعد از ساخت صفحات محصول و لینک‌سازی داخلی، این فاز برای آماده‌سازی سنجش رفتار کاربر و بهبود پایه‌های Core Web Vitals اجرا شد.

## اقدامات انجام‌شده

### ۱) فعال‌سازی سراسری ابزار اندازه‌گیری داخلی
فایل موجود `assets/js/ptf-metrics.js` به همه صفحات عمومی HTML اضافه شد.

نتیجه:
- صفحات عمومی بررسی‌شده: ۵۳۳
- صفحات فاقد metrics قبل از اجرا: ۵۲۵
- صفحات فاقد metrics بعد از اجرا: ۰

این ابزار رویدادهای مهمی مثل page view، کلیک روی RFQ، تماس، واتساپ، ابزارها، مقالات و CTAها را به‌صورت privacy-first ثبت می‌کند.

### ۲) بهبود تصاویر برای CLS و تجربه موبایل
برای تصاویر عمومی سایت:
- `loading="lazy"` به تصاویر فاقد loading اضافه شد.
- برای تصاویر محلی قابل‌شناسایی، `width` و `height` طبیعی تصویر اضافه شد.

نتیجه پس از اجرا:
- کل تگ‌های تصویر عمومی: ۱۱۹۳
- تصاویر فاقد loading: ۰
- تصاویر فاقد width/height: ۴ مورد باقی‌مانده، همگی داینامیک/تمپلیتی هستند و مسیر واقعی ثابت ندارند:
  - `${a.img}` در بلاگ
  - lightbox پروژه‌ها
  - `${b}.svg` برندها
  - `${p.img}` در پروژه‌ها

### ۳) کش مرورگر برای assets استاتیک
یک بلاک محدود و مشخص به `.htaccess` اضافه شد:

`SEO-PERF-2026-08-04 — browser caching for static public assets`

این بلاک برای فایل‌های CSS، JS، تصاویر، SVG، ICO و فونت WOFF2 هدرهای کش و Expires تنظیم می‌کند تا بارگذاری بازدیدهای بعدی سریع‌تر شود.

### ۴) ابزار نگهداری
اسکریپت زیر اضافه شد:

`_tools/seo_performance_foundation.py`

قابلیت‌ها:
- افزودن metrics به صفحات عمومی بدون تکرار
- افزودن `loading="lazy"`
- افزودن `width`/`height` برای تصاویر محلی با کمک `identify`
- عدم ورود به `crm/` و `api/`

- امکان سنجش واقعی مسیرهای تبدیل: مقاله → محصول → RFQ
