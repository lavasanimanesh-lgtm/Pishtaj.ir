   - توضیح: **۷۰ تا ۱۶۵ کاراکتر**
4. ذخیره کنید — تغییر **همان لحظه روی فایل سایت اعمال می‌شود** (نیازی به انتشار جداگانه نیست).
5. بعد از ویرایشِ یک صفحهٔ مهم، در GSC → **URL Inspection → Request Indexing** را بزنید تا سریع‌تر برود.
6. برای کارِ تیمی/گزارش: دکمهٔ **⬇️ CSV** خروجیِ همان نمای فیلترشده را می‌دهد.

### ۶‑۳) محدودیت‌هایی که باید بدانید (این تب همه‌کاره نیست)

- **دادهٔ گوگل را نشان نمی‌دهد** (نمایش/کلیک/جایگاه/وضعیت ایندکس). این‌ها فقط در GSC هستند؛
  برای همین `gsc_import.py` را ساختم تا خروجیِ GSC را کنار همین فهرست بگذارید.
- **محتوای صفحه را عوض نمی‌کند** (فقط سربرگِ متا). بازنویسیِ متنِ مقالات باید جدا انجام شود.
- **«یتیم بودن» و لینک داخلی را نشان نمی‌دهد** — برای آن از `_tools/seo_linkgraph.py` استفاده کنید.
- اگر روی هاست مجوز نوشتن نداشته باشید، تب پیامِ هشدار نشان می‌دهد و ذخیره نمی‌شود
  (در این صورت از هاستینگ بخواهید مجوز write بدهد).
- ویرایشِ canonical را بااحتیاط انجام دهید: یک canonical اشتباه، صفحه را از ایندکس خارج می‌کند.
