## مرحلهٔ ۰ — انتشار تغییرات روی سایت *(قفلِ همه‌چیز — ۱۰ دقیقه)*

**چه می‌خواهیم:** اصلاحاتِ بحرانی (www، صفحهٔ ۴۰۴، اسپم، لینک‌سازی داخلی) الآن فقط در مخزن هستند،
نه روی سایت. تا منتشر نشوند هیچ اثری ندارند.

1. بروید به <https://github.com/shaykhsofla-hash/pishtaj.ir/pull/16>
2. دکمهٔ **Merge pull request** → **Confirm merge**
3. بروید به تب **Actions** → از ستون سمت راست **Deploy to Production** → **Run workflow**
   - فیلد `confirm` را دقیقاً بنویسید: `DEPLOY`
   - فیلد `ref` را همان `main` بگذارید
   - **Run workflow**
4. منتظر بمانید سبز شود (چند دقیقه).

**مطمئن شوید:**
- مرورگر را در حالت ناشناس باز کنید و `https://www.pishtaj.ir` را بزنید
  → باید **خودکار به `https://pishtaj.ir` منتقل شود**.
- `https://pishtaj.ir/logo/` را بزنید → صفحهٔ ۴۰۴ می‌آید؛ روی «خدمات تامین» کلیک کنید
  → باید به `pishtaj.ir/services/` بروید، **نه** به یک آدرسِ عجیبِ تودرتو.

## مرحلهٔ ۱ — روشن‌کردنِ اندازه‌گیری (GA4) *(۱۰ دقیقه — یک‌بار)*

**چه می‌خواهیم:** الآن هیچ ابزار اندازه‌گیری‌ای روی سایت نیست؛ یعنی اثرِ هیچ‌کدام از
کارهای بعدی را نمی‌توانیم بسنجیم. زیرساخت آماده است؛ فقط شناسه کم است.

1. به <https://analytics.google.com> بروید (با همان حساب گوگلی که مالک سایت است).
2. **Admin** (چرخ‌دنده) → **Create** → **Property**
   - نام: `pishtaj.ir` · کشور: Iran · واحد پول: IRR (یا هرچه می‌خواهید)
3. **Data streams** → **Web** → آدرس سایت را `https://pishtaj.ir` بگذارید → **Create stream**
4. در صفحهٔ جریان، **Measurement ID** را کپی کنید — شکلش این است: `G-AB12CD34EF`

**بعد از آن، یکی از این دو را انجام دهید:**
- **ساده‌تر:** شناسه را برای من بفرستید → من در `assets/js/ptf-analytics.js` می‌گذارم و منتشر می‌کنم.
- **خودتان:** روی هاست فایل `assets/js/ptf-analytics.js` را باز کنید و خطِ
  `var GA_MEASUREMENT_ID = 'G-XXXXXXXXXX';` را با شناسهٔ خودتان جایگزین کنید و ذخیره کنید.

**مطمئن شوید:** در GA4 → **Reports → Realtime** بعد از باز کردنِ سایت، یک کاربرِ فعال باید ظاهر شود.

## مرحلهٔ ۲ — وصل‌کردنِ سرچ کنسول به CRM *(۱۰ دقیقه — یک‌بار)*

**چه می‌خواهیم:** به‌جای این‌که هر ماه دستی خروجی بگیرید، دادهٔ زندهٔ گوگل را داخل CRM ببینید.

همهٔ گام‌ها با جزئیات و عیب‌یابی در فایل **`GSC-PANEL-SETUP-FA.md`** هست. خلاصه‌اش:

1. <https://console.cloud.google.com> → پروژه بسازید → **Search Console API** را Enable کنید.
2. **Credentials → Create credentials → Service account** → کلید **JSON** بسازید و دانلود کنید.
3. <https://search.google.com/search-console> → **Settings → Users and permissions → Add user**
   → ایمیلِ سرویس‌اکانت (از فایل JSON) را با سطح **Restricted** اضافه کنید. *این گام حیاتی است.*
4. فایل `api/gsc-config.sample.php` را با نام `api/gsc-config.php` کپی کنید،
   `client_email` و `private_key` را از JSON وارد کنید و روی هاست در پوشهٔ `api/` بگذارید.
5. CRM → منوی **📈 سرچ کنسول** → **⟳ به‌روزرسانی**.

> **مسیر جایگزین (اگر فعلاً نمی‌خواهید API وصل کنید):**
> GSC → **Performance → Queries** → بازهٔ ۳ ماهه → **Export → Download CSV**؛
> همین را برای **Pages** هم تکرار کنید؛ هر دو فایل را برای من بفرستید.

**مطمئن شوید:** پنل باید نمایش/کلیک/کوئری را نشان دهد، نه پیغامِ خطا.

## مرحلهٔ ۳ — پاک‌سازی در سرچ کنسول *(۲۰ دقیقه — بیشترین اثرِ کوتاه‌مدت)*

### ۳‑۱) حذفِ URLهای اسپمِ قمار *(۵ دقیقه)*
GSC → **Removals** → **New request** → این‌ها را یکی‌یکی وارد کنید:

برای پیدا کردنِ بقیه: در گوگل جستجو کنید `site:pishtaj.ir casino` یا در GSC بخش
**Indexing → Pages** را با کلیدواژهٔ `casino` فیلتر کنید.

> این URLها الان ۴۱۰ می‌دهند (من تنظیم کردم)؛ Removals فقط حذف از فهرست را سرعت می‌دهد.

### ۳‑۲) درخواستِ ایندکس برای ۳ صفحهٔ فرصت *(۵ دقیقه)*
این سه صفحه تقاضای واقعی دارند و نزدیکِ صفحهٔ اول‌اند. برای هر کدام:
GSC → نوارِ بالا آدرس را بزنید → **Request Indexing** → منتظر «URL is on Google».

| آدرس | کوئری هدف |
|---|---|
| `https://pishtaj.ir/knowledge-center/rosemount-pressure-transmitter-family.html` | ترانسمیتر فشار روزمونت ۳۰۵۱ (۵۳ نمایش، جایگاه ۱۹) |
| `https://pishtaj.ir/services/products/displacer-level-transmitter.html` | لول ترانسمیتر دیسپلیسر (۱۱ نمایش، جایگاه ۲۶) |
| `https://pishtaj.ir/knowledge-center/steam-control-valve-sizing-guide.html` | کنترل ولو بخار (۶ نمایش، جایگاه ۱۸) |

### ۳‑۳) استخراجِ فهرستِ ۴۰۴ها برای من *(۵ دقیقه)*
GSC → **Indexing → Pages** → روی کارتِ **Not found (404)** کلیک کنید → **Export** (دانلود CSV)
→ **برای من بفرستید** تا برای تک‌تکشان ریدایرکت ۳۰۱ بنویسم (الآن فقط ۸ نمونه را حدس زده‌ام).

### ۳‑۴) دو عدد را برای من بنویسید *(۱ دقیقه)*
در همان صفحهٔ **Indexing → Pages**، عددِ **Indexed** و **Not indexed** را یادداشت کنید.
این دو عدد خط مبنای سنجشِ موفقیتِ کلِ این پروژه است.

## مرحلهٔ ۴ — اصلاحِ متاها از تب سئوی CRM *(۱ تا ۲ ساعت — قابل تقسیم به چند نوبت)*

**چه می‌خواهیم:** ۲۶۷ صفحه توضیحِ بلند و ۷۷ صفحه عنوانِ بلند دارند (در نتایج گوگل بریده می‌شوند).

1. CRM → **🎛 مدیریت سایت (CMS)** → تب **🔍 سئوی صفحات**
2. روی چیپِ **«توضیح بلند»** بزنید (فقط همان صفحات فیلتر می‌شوند).
3. برای هر صفحه **✏️ ویرایش** → متن را کوتاه کنید تا شمارنده **سبز** شود:
   - عنوان: **۳۰ تا ۶۵ کاراکتر**
   - توضیح: **۷۰ تا ۱۶۵ کاراکتر**
4. **🚀 اعمال روی سایت** → بعداً همین را برای چیپِ **«عنوان بلند»** تکرار کنید.

**نکتهٔ کارایی:** روی ۳۰–۴۰ صفحهٔ مهم‌تر تمرکز کنید (آن‌هایی که در مرحلهٔ ۳ ایندکس کردید +
صفحات اصلی خدمات/تامین‌کنندگان)؛ بقیه را بعداً می‌توان انجام داد.
دکمهٔ **⬇️ CSV** فهرست را می‌دهد تا بتوانید به همکار بسپارید.
