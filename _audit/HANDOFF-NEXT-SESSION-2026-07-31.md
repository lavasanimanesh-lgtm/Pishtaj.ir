6. گردش‌کار ۱۵ مرحله‌ای استاندارد هر batch (کاملاً مستند در خلاصهٔ این جلسه) را دنبال کن: چک plan.json → بررسی title مقالهٔ twin → نوشتن batch script → اجرا و شمارش کلمه → extend تا ≥۱۵۰۰ کلمه → QA (تک H1، JSON-LD معتبر، بستن درست تگ‌های `note-box`/`ok-box`) → grep برای لینک‌های داخلی به فایل قدیمی → حذف فایل‌های قدیمی → افزودن RewriteRule ریدایرکت → افزودن لینک متقابل در twin → ثبت در index.html → `node --check` روی اسکریپت استخراج‌شده → `build_sitemap.py` سپس `audit.py` (باید «۰ خطا» شود) → کامیت با پیام تفصیلی فارسی → push.
7. همیشه قبل از شروع کار جدید: `git fetch` + مقایسه با remote + در صورت اختلاف `git reset --hard origin/arena/019fa4f1-pishtaj-ir` (رویهٔ استاندارد رفع ناهماهنگی سندباکس/گیت که چندبار در این جلسه لازم شد).
