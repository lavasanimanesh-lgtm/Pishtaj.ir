# 🔍 برنامه ممیزی جامع پروژه PTF (انسانی + خودکار)

**تاریخ شروع:** ۱۴۰۵/۰۴/۲۸ (July 2026)
**روش‌شناسی:** تحلیل ایستای کد + تست‌های رفتاری + بررسی یکپارچگی
**هدف:** شناسایی تمام باگ‌ها و ثبت در بک‌لاگ با اولویت‌بندی فوری

## فازبندی

### فاز ۱: تحلیل ایستا (Static Analysis) — خودکار
- بررسی ارجاعات ناشناخته (undefined functions/variables)
- بررسی ناسازگاری schema داده
- بررسی توابع تعریف‌شده ولی استفاده‌نشده (dead code)
- بررسی استفاده از توابع تعریف‌نشده (broken refs)
- بررسی race conditions و event handler leak
- بررسی مسیرهای کور (unreachable code)

### فاز ۲: تست‌های رفتاری (Behavioral) — ۶۲ ماژول
برای هر ماژول:
- سناریوهای خوش‌بینانه (Happy Path)
- سناریوهای مرزی (Edge Cases)
- سناریوهای نامعتبر (Invalid Input)
- سناریوهای همزمانی (Concurrency)
- تست بازخورد متقابل (Cross-module impact)

### فاز ۳: بررسی یکپارچگی بین ماژولی
- سازگاری schema بین ماژول‌ها
- صحت هوک‌ها (buildSettings, buildDashboard, renderXxx)
- سازگاری RBAC در همه پنل‌ها
- سازگاری تاریخ (ISO vs شمسی)
- سازگاری ارز (IRR vs ارز آزاد)

### فاز ۴: کیس‌های استادی (Master Cases)
- سناریوهای واقعی کسب‌وکار PTF
- فاز کامل: ثبت RFQ → تأمین → CO/TC → تحویل → فاکتور → تسویه → بایگانی
- فاز کامل R9: هزینه → تنخواه → سهامداران → سود سال → تقسیم
- فاز کامل R12: برد → سند قطعی → QC → ارسال → تحویل → فاکتور → مختومه

### فاز ۵: ثبت بک‌لاگ اولویت‌بندی‌شده
- Critical (رنگ قرمز): باگ‌های بحرانی داده/مالی/امنیت
- High (نارنجی): باگ‌های قابل‌توجه در عملکرد
- Medium (زرد): باگ‌های UX/UI
- Low (خاکستری): بهبودها و کدنویسی تمیز
