## 🔧 روش بارگذاری

### روش ۱: دستی از طریق UI (توصیه‌شده)
1. وارد CRM شو با admin/ptf2026
2. به ترتیب:
   - ابتدا تامین‌کنندگان (از تنظیمات → کاربران یا از پنل تامین‌کنندگان)
   - سپس مشتریان
   - سپس کالاها
   - سپس RFQ‌ها
   - سپس پیشنهادها
   - سپس فاکتورها
3. داده‌های بالا را وارد کن

### روش ۲: از طریق اکسل (سریع‌تر)
1. فایل اکسل نمونه را از `_human_test/v20.8/sample-data.xlsx` بارگذاری کنید
2. در CRM از منوی «ورود اکسل» هر ماژول استفاده کنید

### روش ۳: از طریق اسکریپت (برای ایجنت)
```javascript
// بارگذاری داده نمونه
loadSampleData();
```
