A106 وA333 وAPI 5L وفلنجات ASME B16.5 وتوصيلات وحشوات مع MTC 3.1.

الصمامات الصناعية

بوابة API 600، كروي API 6D، فحص وفراشة API 609، تحكم وأمان ومحرّكات.

الكهرباء الصناعية

لوحات LV وقواطع Siemens / ABB / Schneider وPLC وVFD وUPS ومحولات.

الفحص والجودة
