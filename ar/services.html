خدمات التوريد

الأنابيب والفلنجات

A106 وA333 وAPI 5L وفلنجات ASME B16.5 وتوصيلات وحشوات مع MTC 3.1.

الصمامات الصناعية

بوابة API 600، كروي API 6D، فحص وفراشة API 609، تحكم وأمان ومحرّكات.

الكهرباء الصناعية

لوحات LV وقواطع Siemens / ABB / Schneider وPLC وVFD وUPS ومحولات.

أجهزة القياس

Rosemount 3051 وYokogawa وتدفق كوريوليس/مغناطيسي ورادار مستوى وحرارة.

الفحص والجودة

TPI وNDT وMTC 3.1/3.2 وPMI وNACE MR0175 وشهادات معايرة.

المشتريات واللوجستيات

توريد من أوروبا وآسيا، تخليص، FOB/CIF/DDP وتجميع متعدّد المورّدين لجداول EPC.
