معرفی صنعت

صنعت نفت و گاز ایران: ستون فقرات اقتصاد، نیازمند تامین‌کننده تخصصی

صنعت نفت و گاز ایران با ذخایر اثبات شده گاز در رتبه دوم جهان و ذخایر نفت در رتبه سوم، یکی از بزرگترین صنایع کشور است. این صنعت با ۳ زیربخش Upstream (بالادست)، Midstream (میان‌دست) و Downstream (پایین‌دست) طیف وسیعی از پروژه‌های اکتشاف، استخراج، انتقال، پالایش و توزیع را شامل می‌شود.

تامین تجهیزات این صنعت پیچیده‌ترین چالش‌های فنی را دارد: الزامات Hazardous Area (محیط انفجار)، گواهی‌های NACE برای سرویس Sour (H2S)، انطباق با API ها (6A، 6D، 610، 618)، Vendor List های سختگیرانه شرکت‌های ملی و EPC، و زمان‌بندی فشرده پروژه‌های توسعه و اورهال. پیشرو تجهیز فرتاک با تمرکز تخصصی روی این صنعت، با ادبیات فنی پروژه‌های نفت و گاز ایرانی کاملاً آشناست.

۳ زیربخش اصلی صنعت نفت و گاز و تجهیزات مرتبط

۱) Upstream (بالادست) — اکتشاف، حفاری، استخراج

  • Wellhead و Christmas Tree — مطابق API 6A، با کلاس‌های PSL 1-4 و فشار 2000-15000 psi
  • Separator (Two-Phase / Three-Phase) — جداسازی نفت، گاز و آب
  • تجهیزات Mud System — Shale Shaker، Desander، Desilter، Mud Pump
  • Pipeline Valves (API 6D) — Ball Valve، Gate Valve، Check Valve فشار بالا
  • تجهیزات MEG/TEG (پیشگیری Hydrate) — Injection System، Regeneration Unit
  • Surface Production Equipment — Heater Treater، Free Water Knockout، LACT Unit

۲) Midstream (میان‌دست) — انتقال، ذخیره‌سازی

  • Pipeline Components — لوله API 5L (X42-X70)، Bend، Tee، Reducer، Insulating Joint
  • Compressor Station Equipment — Gas Compressor API 618، Cooler، Scrubber، Filter
  • Metering Stations — Ultrasonic Flowmeter، Coriolis، Provers، Flow Computer
  • Pig Launchers و Receivers — مطابق ASME B31.4 / B31.8
  • Cathodic Protection — Transformer Rectifier، Sacrificial Anode، Reference Cell
  • Storage Tanks — API 650 (آب)، API 620 (LPG/LNG)، Floating Roof Tank

۳) Downstream (پایین‌دست) — پالایش، توزیع

  • تجهیزات پالایشگاهی — Atmospheric Distillation Unit، Vacuum Distillation، FCC، Hydrocracker
  • Heat Exchangers (TEMA) — Shell & Tube، Air Cooler API 661، Plate & Frame
  • Fired Heaters و Furnaces — مطابق API 560
  • Process Pumps API 610 — OH2، BB2، BB5، VS برای سرویس‌های مختلف
  • Control Valves — مطابق ISA + IEC 60534 برای سرویس‌های فرایندی
  • تجهیزات Storage & Loading — Loading Arm، Vapor Recovery، Tank Gauging

سوالات متداول

Upstream، Midstream و Downstream چه تفاوتی دارند؟

Upstream (بالادست): اکتشاف، حفاری، استخراج نفت و گاز از مخزن. شامل Wellhead، Christmas Tree، Separator، MEG/TEG Unit. Midstream (میان‌دست): انتقال و ذخیره‌سازی. شامل Pipeline، Compressor Station، Storage Tank. Downstream (پایین‌دست): پالایش، توزیع، فروش. شامل پالایشگاه، پتروشیمی، توزیع سوخت.

NACE MR0175 چیست و چرا برای پروژه‌های ترش (Sour) الزامی است؟

NACE MR0175 / ISO 15156 استاندارد بین‌المللی برای انتخاب متریال مقاوم به Sulfide Stress Cracking (SSC) در سرویس H2S است. هر تجهیز در پروژه ترش (Sour Service) باید گواهی NACE داشته باشد. این استاندارد محدودیت‌های سختی (Hardness)، ترکیب شیمیایی و Heat Treatment را تعریف می‌کند. عدم رعایت منجر به ترک‌خوردگی فاجعه‌بار می‌شود.

Vendor List در پروژه‌های نفت و گاز چقدر مهم است؟

Vendor List لیست برندهای مجاز کارفرما برای هر دسته تجهیز است. در پروژه‌های NIOC، NIGC، NPC و... این لیست‌ها معمولاً 3-5 برند برای هر تجهیز دارند (مثلاً برای ولو: Velan، KITZ، Cameron، Bonney Forge). تامین خارج از Vendor List نیاز به Vendor Approval Request (VAR) و طی کردن فرآیند طولانی دارد.

Wellhead و Christmas Tree چیست؟

Wellhead: تجهیز بالای چاه که فضای ساختاری بین Casing های مختلف را آب‌بندی می‌کند و نقطه اتصال تجهیزات بالاتر است. Christmas Tree (X-Tree): مجموعه‌ای از ولوها، فلنج‌ها و فیتینگ‌ها روی Wellhead که جریان نفت/گاز را کنترل می‌کند. شامل Master Valve، Wing Valve، Swab Valve، Choke. مطابق API 6A با کلاس‌های PSL 1-4 ساخته می‌شود.

Hazardous Area Classification در نفت و گاز چگونه است؟

محیط‌های نفت و گاز عمدتاً Zone 1 و Zone 2 طبقه‌بندی می‌شوند. Zone 0 فقط داخل مخازن نفت سبک. تجهیزات برق باید Ex d (Flameproof)، Ex e (Increased Safety) یا Ex ia/ib (Intrinsic Safety) باشند. ابزار دقیق معمولاً Ex ia. کابل‌ها باید Armoured (SWA) و Cable Gland با Ex Approval. همه با گواهی ATEX یا IECEx.

آیا تامین تجهیزات اضطراری برای Shutdown هم انجام می‌دهید؟

بله، تامین اضطراری اقلام بحرانی برای Plant Shutdown و Turnaround از تخصص ما است. در این موارد، زمان تحویل بحرانی است (گاهی چند روز) و ما با شبکه تامین گسترده و انبارهای داخلی، اقلام پرکاربرد را در سریع‌ترین زمان ممکن تامین می‌کنیم. سفارش اضطراری معمولاً با هزینه حمل سریع‌تر و قیمت متفاوت همراه است.

درخواست استعلام پروژه نفت و گاز

برای ارائه خدمات تامین به پروژه نفت و گاز خود، کافی است MTO، Datasheet ها یا Tag List به همراه Vendor List و الزامات خاص پروژه (NACE، Hazardous Area، SIL، TPI) را به واحد بازرگانی ارسال کنید. کارشناسان متخصص نفت و گاز ما پس از بررسی، گزینه‌های تامین را اعلام می‌کنند.
