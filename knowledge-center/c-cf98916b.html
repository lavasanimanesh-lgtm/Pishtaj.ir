API 5L PSL1 و PSL2

API 5L استاندارد لوله خطوط لوله انتقال نفت و گاز است. PSL1 سطح استاندارد و PSL2 سطح بالاتر با الزامات سخت‌گیرانه‌تر شامل تست ضربه (CVN) و کربن معادل (CEV) محدود می‌باشد. برای خطوط اصلی فشار قوی PSL2 الزامی است.

تفاوت PSL1 و PSL2

PSL2 نیازمند تست ضربه Charpy V-Notch در دمای ۰°C یا ۴۶-°C است. همچنین حداکثر CEV (کربن معادل) برای PSL2 محدود شده تا جوش‌پذیری بهبود یابد.
