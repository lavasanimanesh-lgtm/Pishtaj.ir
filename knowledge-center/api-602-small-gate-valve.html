استاندارد API 602 — شیر دروازه‌ای سایز کوچک

مقاله تخصصی استاندارد API 602 — شیر دروازه‌ای سایز کوچک — راهنمای جامع برای مهندسان و کارشناسان خرید تجهیزات صنعتی

استاندارد API 602 مرجع ساخت شیرهای دروازه‌ای (و کره‌ای و یک‌طرفه) فورج‌شده با سایز کوچک برای سرویس‌های پر‌فشار پالایشگاهی است. اگر در یک وندورلیست مشخصه «Gate Valve, API 602, Class 800» دیده‌اید، این مقاله دقیقاً همان چیزی است که باید پیش از استعلام بدانید.

دامنهٔ استاندارد و محدودهٔ سایز

API 602 شیرهای فولادی فورج‌شده در محدودهٔ NPS 1/4 تا NPS 2 (سایزهای کوچک) را پوشش می‌دهد و رایج‌ترین کلاس‌های آن Class 800 و Class 1500 است. بدنه از شمش یا قطعهٔ فورج تهیه می‌شود، نه ریخته‌گری؛ همین موضوع چگالی متالورژیکی بالاتر و ریسک عیب ریخته‌گری کمتر را تضمین می‌کند.

تفاوت API 602 با API 600 و API 603

API 600 برای شیرهای دروازه‌ای ریخته‌گری‌شده در سایزهای بزرگ‌تر و API 603 برای نسخه‌های استنلس استیل نوشته شده است. API 602 مخصوص سایز کوچک، کلاس فشار بالا و بدنهٔ فورج است و معمولاً در خطوط درین، ونت، نمونه‌گیری و اتصالات ابزار دقیق با فشار بالا به کار می‌رود.

انواع ساخت و متریال

رایج‌ترین متریال بدنه ASTM A105 (کربن استیل)، A182 F316/F316L (استنلس) و A182 F22/F91 (آلیاژی) است. طراحی می‌تواند گوه صلب، گوه منعطف یا دو تکه باشد؛ برای دماهای بالا گوهٔ منعطف به دلیل آزادی انبساط حرارتی ترجیح داده می‌شود.

نکات استعلام و بازرسی

در استعلام حتماً کلاس فشار، جنس بدنه و تریم، نوع انتها (رزوه‌ای NPT / ساکت‌ولد / فلنجی) و استاندارد تست API 598 را مشخص کنید. در بازرسی ورودی، گواهی MTC 3.1 و نتایج تست هیدرواستاتیک هر شیر را با شمارهٔ Heat تطبیق دهید؛ PMI بدنهٔ فورج نیز در پروژه‌های حساس الزامی است.

خطاهای رایج

  • استعلام سایز بزرگ‌تر از ۲ اینچ با API 602 به جای API 600.
  • نادیده‌گرفتن کلاس ۱۵۰۰ در سرویس‌های فشار بالا.
  • سفارش بدنهٔ ریختگی وقتی مشخصهٔ پروژه فورج است.
  • عدم توجه به جهت جریان در شیرهای کره‌ای API 602.

بازرسی تحویل و مدارک

هنگام تحویل، تعداد و سایز شیرها، کلاس فشار و علامت‌گذاری بدنه (Body Marking) را با PO تطبیق دهید. مدارک موردنیاز شامل گواهی MTC 3.1، گزارش تست هیدرواستاتیک و در صورت الزام پروژه، گزارش PMI است. هر شیر باید شمارهٔ Heat خوانا و قابل ردیابی داشته باشد.

پرسش‌های متداول

آیا API 602 فقط شیر دروازه‌ای را پوشش می‌دهد؟

خیر؛ علاوه بر شیر دروازه‌ای، شیر کره‌ای و شیر یک‌طرفهٔ فورج‌شده در سایزهای کوچک را هم در بر می‌گیرد، اما کاربرد غالب آن شیر دروازه‌ای است.

تفاوت Class 800 و Class 1500 در API 602 چیست؟

هر دو کلاس فشاری هستند؛ Class 1500 برای فشارهای بالاتر طراحی شده و ضخامت دیواره و الزامات ساخت سخت‌گیرانه‌تری دارد. انتخاب بر اساس فشار طراحی خط انجام می‌شود.

برای چه سرویس‌هایی از API 602 استفاده می‌شود؟

عمدتاً خطوط درین و ونت، اتصالات نمونه‌گیری، خطوط بخار فشار بالا و سرویس‌های شیمیایی در پالایشگاه و پتروشیمی که در آن‌ها به شیر سایز کوچک با بدنهٔ فورج نیاز است.
