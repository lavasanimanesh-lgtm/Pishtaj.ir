مقایسه شیر دروازه‌ای (Gate) و کروی (Globe) | افت فشار و تنظیم جریان

تفاوت Gate Valve و Globe Valve؛ کاربرد در قطع و وصل در برابر تنظیم جریان، افت فشار، جهت نصب، تعمیر و انتخاب در خطوط بخار و فرایندی.

Gate Valve چیست؟

Gate Valve (شیر دروازه‌ای) یک دیسک تخت یا گُوِه‌ای (Wedge) دارد که به‌صورت عمودی بالا و پایین می‌رود و جریان را کاملاً قطع یا برقرار می‌کند. در حالت باز، مسیر تقریباً مستقیم و بدون مانع است؛ در نتیجه افت فشار بسیار کم دارد. Gate برای قطع و وصل (On/Off) طراحی شده، نه تنظیم جریان.

Globe Valve چیست؟

Globe Valve (شیر کروی) یک دیسک دارد که روی نشیمن Z-shaped می‌نشیند و مسیر جریان مجبور به تغییر جهت است. این طراحی امکان تنظیم دقیق جریان (Throttling) و کنترل فشار/دبی را می‌دهد اما افت فشار بالایی دارد. Globe در ایستگاه‌های تقلیل فشار، خطوط بخار و کاربردهای تنظیمی رایج است.

Gate Valve

قطع/وصل با افت فشار کم. مسیر مستقیم. بدون Throttling. ارزان‌تر در سایز بزرگ.

Globe Valve

تنظیم دقیق جریان، آب‌بندی خوب. افت فشار بالا. جهت‌دار.

استانداردها و متریال

  • استاندارد طراحی: API 600 (Gate فولادی کلاس بالا)، API 602 (Gate کوچک)، BS 1873 (Globe)، API 623 (Globe فولادی).
  • متریال بدنه: A216 WCB (کربن استیل)، A352 LCC/LCB (دمای پایین)، CF8/CF8M (استینلس)، A217 WC6/WC9 (آلیاژی Cr-Mo برای بخار داغ).
  • Trim (قطعات داخلی): API 600 Trim Number مشخص می‌کند؛ برای سرویس ترش از 13Cr و Stellite و متریال کنترل‌شده NACE.
  • تست: API 598 (تست نشتی بدنه و نشیمن) یا ISO 5208؛ Fire-Safe API 607 در مناطق آتش‌خیز.
نکته فنی: در ایستگاه‌های کنترل، ترکیب رایج یک Globe (کنترل) به‌علاوه یک Gate برای ایزولاسیون قبل و بعد، به‌علاوه یک بای‌پس است. از Gate برای Throttling هرگز استفاده نکنید؛ خرابی نشیمن در طول زمان به نشتی دائمی منجر می‌شود.

نکات تامین و نصب

در Gate، برای جلوگیری از قفل حرارتی (Thermal Binding) در خطوطی که شیر بسته و بین دو ایزوله قرار می‌گیرد، گاه یک بای‌پس کوچک یا شیر تخلیه لازم است. Globe جهت نصب دارد؛ فلش روی بدنه مسیر جریان را نشان می‌دهد و در خطوط بخار معمولاً جریان از زیر دیسک به بالا است تا در صورت خرابی ساقه، شیر خودبه‌خود باز نماند. متریال پکینگ (گرافیت منعطف یا PTFE) باید با دما و سیال سازگار باشد.

چه زمانی کدام را انتخاب کنیم؟

  • نیاز به قطع/وصل تمیز با افت فشار کم → Gate.
  • نیاز به تنظیم/کنترل دبی یا فشار → Globe.
  • برای بخار داغ، Globe در کنترل و Gate در ایزولاسیون به‌کار می‌رود.

سایر انواع شیر و انتخاب در ایستگاه کنترل

در ایستگاه‌های کنترل و شیرهای ایزولاسیون، معمولاً ترکیبی از Gate، Globe، Ball و Check دیده می‌شود. برای ایزولاسیون با افت فشار کم و سایز بزرگ، Gate (یا در سرویس‌های مدرن، Trunnion Ball) انتخاب می‌شود. برای تنظیم دستی جریان، Globe با امکان Throttling به‌کار می‌رود؛ اما در کنترل خودکار، کنترل ولو با اکچویتور پنوماتیک و پوزیشنر که گاه طراحی Globe-style دارد استفاده می‌شود. برای جلوگیری از برگشت جریان، Check Valve بین پمپ/تجهیز و خط نصب می‌گردد. در سرویس بخار، Globe با دیسک Plug برای کنترل و Gate برای ایزولاسیون، به‌همراه تله بخار (Steam Trap) ترکیب استاندارد است.

انتخاب نوع استم (Rising Stem یا Outside Screw & Yoke) و عملگر (دستی، گیربکسی، پنوماتیک، برقی) به گشتاور مورد نیاز، دفعات عملکرد و امکان اپراتوری در ارتفاع بستگی دارد. در شیرهای Gate سایز بزرگ، Gear Operator لازم است و برای کاربردهای ایمنی، عملگر با Fail-Safe (باز/بسته در قطع هوا) تعریف می‌شود. توجه کنید Gate هرگز برای Throttling طولانی‌مدت نباید نیمه‌باز بماند؛ لرزش دیسک باعث فرسایش نشیمن و نشتی دائمی می‌شود.

چک‌لیست RFQ شیرآلات Gate و Globe

  • استاندارد طراحی: API 600/602/603 برای Gate، BS 1873 یا API 623 برای Globe.
  • کلاس فشار و سایز: 150–2500# و NPS.
  • متریال بدنه و Trim: WCB، LCC، CF8M، WC6/WC9 با کد Trim API 600.
  • نوع اتصال: Flanged (RF/RTJ)، Buttweld، Socket Weld یا Threaded.
  • نوع استم و بونت: OS&Y، Bolted Bonnet، Pressure Seal.
  • پکینگ و گسکت: گرافیت منعطف، PTFE، Spiral Wound گرافیتی.
  • الزامات ویژه: NACE، Fire-Safe API 607، Low Emission (API 641/ISO 15848-1).
  • عملگر: Handwheel، Gear، Pneumatic (با ضمیمه)، Electric، با یونیت کنترل موقعیت.
  • تست: API 598 یا ISO 5208 (نشتی صندلی و بدنه)، تست Fire Safe در صورت الزام.
توصیه نگه‌داری: شیرهای Gate و Globe ذخیره در انبار باید کاملاً بسته (نه با گشتاور کامل) و با محافظ فلنج نگهداری شوند. قبل از نصب، تست صندلی و حرکت استم چک شود.

هیدرولیک، ضریب جریان و کاویتاسیون

Gate در حالت کاملاً باز تقریباً مسیر مستقیم دارد و Cv بسیار بالاست؛ افت فشار ناچیز است و برای isolation خطوط انتقال مناسب است. Globe مسیر Sشکل دارد و Cv کمتر؛ همان ویژگی آن را برای throttling قابل‌پیش‌بینی می‌کند. اگر Gate را نیمه‌باز بگذارید، دیسک ارتعاش می‌کند، نشیمن ساییده می‌شود و شیر دیگر آب‌بند نمی‌شود. در سرویس مایع با ΔP بالا، Globe هم کاویتاسیون می‌کند؛ باید trim ضدخفره (multi-step، cage) یا شیر کنترل واقعی انتخاب شود نه Globe دستی ساده.

استاندارد طراحی و تست

API 600 (Steel Gate)، API 602 (compact forged ≤DN100)، API 603 (ضدزنگ سبک) و BS 1873 / API 623 برای Globe رایج‌اند. تست پوسته و نشیمن طبق API 598: فشار هیدرو بدنه ۱٫۵ برابر، تست نشیمن ۱٫۱ برابر. کلاس نشتی فلزی معمولاً API 598 یا ISO 5208 Rate D/E است؛ برای گاز سمی Rate A/B با نشیمن نرم لازم است. مشخص کردن «API 600 + API 598 + NACE MR0175» در RFQ جلوی پیشنهاد شیر ساختمانی ارزان را می‌گیرد.

ساقه، گسکت درپوش و fugitive emission

Gate و Globe هر دو rising stem یا non-rising دارند. در فضای محدود زیرزمین non-rising راحت‌تر است اما موقعیت دیسک مبهم می‌ماند. پکینگ گرافیت + latern ring و در صورت نیاز bellows seal برای VOC طبق ISO 15848 یا API 624 است. در سرویس هیدروژن یا بنزن، emission تست کارخانه را بخواهید. گسکت درپوش (body-bonnet) اسپیرال‌ووند با حلقه داخلی برای کلاس ۳۰۰+ توصیه می‌شود.

عملگر و زمان قطع

Gate سایز بزرگ گشتاور شکست بالایی دارد؛ گیربکس و اکچویتور برقی باید با stem thrust نه فقط گشتاور انتخاب شود. Globe برای کنترل با اکچویتور پنوماتیک و پوزیشنر دقیق‌تر است. زمان بسته شدن سریع Gate در مایع باعث ضربه قوچ می‌شود؛ شیر قطع اضطراری را با تحلیل surge انتخاب کنید. برای blowdown گاز، گاهی Ball سریع‌تر و مطمئن‌تر از Gate است.

در خطوط بخار، Globe زاویه‌ای (angle) افت کمتری از Globe مستقیم دارد و در ایستگاه تقلیل فشار کنار تله بخار دیده می‌شود. Gate چدنی ساختمانی را با Gate فولادی API عوض نکنید فقط به‌خاطر ظاهر مشابه؛ فشار و دمای بخار نشیمن برنزی را خراب می‌کند. همیشه PMS پروژه را منبع حقیقت بگیرید نه کاتالوگ عمومی.

تست کرایوژنیک برای اکسیژن مایع و LNG روی هر دو نوع طبق BS 6364 انجام می‌شود و نشیمن و پکینگ ویژه می‌خواهد. شیر اتاق‌دمای معمولی را به سرویس سرد نفرستید. امتداد ساقه (extended bonnet) طول و وزن را عوض می‌کند و روی ساپورت لوله اثر می‌گذارد.

مقالات مرتبط: راهنمای گیت ولو و راهنمای گلوب ولو.

برای سرویس هیدروژن با فشار بالا، انتخاب مواد و نشتی ساقه مهم‌تر از نوع شیر است. مشخصات جدید هیدروژن گاهی Ball را ترجیح می‌دهند؛ Gate و Globe را فقط با تایید مهندسی مواد بخرید.

پرسش‌های متداول

چرا Gate برای تنظیم جریان مناسب نیست؟

Gate Valve طوری طراحی شده که یا کاملاً باز است یا کاملاً بسته. در حالت نیمه‌باز، دیسک در معرض ارتعاش و فرسایش جریان قرار می‌گیرد و نشیمنگاه به‌سرعت آسیب می‌بیند.

چرا Globe افت فشار بیشتری دارد؟

در Globe، مسیر جریان مجبور به تغییر جهت (معمولاً ۹۰ درجه از زیر دیسک به بالا) است که افت فشار قابل‌توجهی ایجاد می‌کند. این هزینه، با قابلیت تنظیم دقیق جریان و آب‌بندی بهتر جبران می‌شود.

آیا می‌توان Gate را برعکس نصب کرد؟

نصب صحیح Gate معمولاً به جهتی حساس نیست (دو طرفه است)، اما Globe جهت‌دار است؛ فلش روی بدنه جهت جریان را نشان می‌دهد و نصب معکوس می‌تواند عملکرد و عمر سیل/درپوش را تحت‌تاثیر قرار دهد.

کدام برای بخار بهتر است؟

برای قطع و وصل خط بخار، Gate در کلاس مناسب به‌کار می‌رود. برای کنترل/تنظیم دبی یا فشار بخار (مثل بای‌پس تله بخار یا کنترل تغذیه بویلر) Globe به‌دلیل قابلیت Throttling ارجح است.

نیاز به استعلام یا مشاوره فنی دارید؟

مشخصات فنی پروژه (استاندارد، سایز، کلاس، کمیت) را ثبت کنید تا کارشناسان مهندسی فروش پیشنهاد فنی-تجاری دهند.
